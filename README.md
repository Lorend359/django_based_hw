# Учебный проект: Простой сервер с Bootstrap-версткой

Этот проект — часть домашнего задания. Он включает HTML-страницы, сверстанные с помощью Bootstrap, и простой сервер на Python без фреймворков.

## Состав проекта

```
django_based_hw/
├── pages/          # HTML-страницы
│   ├── index.html
│   ├── catalog.html
│   ├── category.html
│   └── contacts.html
├── src/
│   └── server.py   # сервер Python
├── .gitignore
└── README.md
```

## Как запустить сервер

1. Откройте терминал и перейдите в папку проекта.
2. Запустите файл `server.py`:

```bash
python src/server.py
```

3. Перейдите в браузере по адресу:
   [http://127.0.0.1:8000](http://127.0.0.1:8000)

## Что делает сервер

* Возвращает HTML-страницы при GET-запросах.
* Если путь не найден — показывает страницу "Контакты".
* При POST-запросе (например, отправке формы) данные выводятся в консоль.

## Зависимости

* Только Python 3. Никакие библиотеки устанавливать не нужно.
